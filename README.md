# SEAT — Student Enrollment Accountability & Tracking

Verification & reconciliation layer for AICTE's student-data ecosystem.

## Quick Start

docker compose up --build

- Backend:  http://localhost:8000/docs
- Frontend: http://localhost:5173
- Health:   http://localhost:8000/api/v1/health
